# UH33
Сценарные тесты для конфигурации 1С:Управление Холдингом

## Ветка uh-file-base-env

Не для вливания. Это `uh-3.3.3.72-fixes` плюс условия выполнения: файловая база, лицензия для
разработчиков, все разделы подряд в одной базе. Проверки сценариев не ослаблены: добавлены только ожидания, повторы
и проверки собственного ввода.

- Подключение тестового клиента обёрнуто в `Попытка ... Исключение / И Пауза 30 / повторное подключение`: при
  медленном старте клиента первая попытка не успевает.
- Маски заголовков окон `' *'` заменены на `' **'` (замечание проверки синтаксиса VA, нужно для запуска через MCP;
  пакетный запуск работает и без них).
- Паузы и явный переход к строке или реквизиту там, где форма под нагрузкой не успевала: резервы в
  `4_Планирование\02`, критерии конкурентного листа в `06`, переоткрытие «Корпоративные закупки» после включения
  подсистем.
- Проверка собственного ввода с повтором («Место проведения», «Результат работы комиссии», состав комиссии): серверный
  контроль формы под нагрузкой затирал поле.
- `6_Закупки` идут в одной базе с остальными разделами (у вендора — на отдельной базе): 10.08 перед заполнением ПТУ
  удаляет закупочные цены Товар1 из `ЦеныНоменклатурыДокументов`, иначе цена берётся из прошлых закупок; тегом
  `@UH33_dup` помечены 26 сценариев `6_Закупки\02`, повторяющих `1_НСИ\02`, — в общей базе их пропускаем, чтобы
  не создавать контрагентов и НСИ второй раз.
- 05.05: в эталоне `ВА_ЗаполнениеИзРН_Движения_1.mxl` пятый знак после запятой в трёх ячейках заменён маской `*`
  (215 126,9181\*, 46 386,7417\*, 98 823,9280\*): на файловой базе он расходится (вопрос вендору в issue).
- `2_Дымовые_3.3.3.72` — набор дымовых тестов для 3.3.3.72: генератор VA на всю конфигурацию, исключения в
  `ОбъектыИсключения` (вендорские и найденные прогоном). 6282 сценария.

Проверено на УХ 3.3.3.72, платформе 8.3.27.2214 и Vanessa Automation 1.2.043.47, файловая база: сценарные — сплошной
цепочкой от пустой базы; дымовые — без падений, кроме зависящих от состояния стартовой базы (ввод на основании
первого документа вида).
